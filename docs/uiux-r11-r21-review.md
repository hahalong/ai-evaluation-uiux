# UI/UX R11 / R2.1 整合说明

更新日期：2026-11-22（北京时间）。基线：GitHub main `d7f5f63`，原站点布局和共享台账。

需求依据：评测资产模块 R11；对象接入与任务管理详细 PRD R2.1。本次为交互原型更新，未修改主 PRD。

## 需求与页面对应

| 需求 | 页面与行为 |
| --- | --- |
| R11 业务模板起步 | 原资产编辑器先选择业务用途，模板可修改；保留手工创建与批量导入 |
| R11 用例内容与自动化分离 | 用例可先保存再绑定程序；保留已登记程序、源码发现、参数映射和关系确认 |
| R11 只读发布版本 | 已发布用例展示快照；任务采用前预览，显式确认精确版本 |
| R11 场景示例 | Office、RAG、携宠示例；字段说明、必填优先与高级项折叠 |
| P02 对象身份与版本 | 广场登记对象草稿、添加固定版本、按版本保存接入配置 |
| P02 五种接入方式 | API、网页、容器、程序、SDK；自动执行时显示对应配置 |
| P02 三条执行路径 | 自动执行、人工执行、已有记录接收；后两者不要求自动端点或预算 |
| P02 统一台账 | 需求入口、对象发起、独立人评共享任务；复制为新任务与原任务新修订分开 |
| P02 条件评分 | 模板预填按指标评分配置，支持自动、人工和混合；必要人评未完成不得通过 |
| P02 检查、确认、冻结、运行 | 修改语义配置使旧检查/确认失效；冻结不会调用对象或产生运行 |
| P02 接收与取消 | 来源编号去重，错版本/缺证据隔离；请求取消与外部核实终态分开 |
| P02 报告与验收 | 不可变快照、已知失败与未知并存、验收绑定精确报告且不覆盖质量结论 |
| P02 历史追溯 | 修订、运行、证据、报告保留；历史运行只读且使用原冻结评分范围 |

## 一致性与简化

- 沿用原站点导航、对象库和资产库；新任务收敛为六步，同一步骤复用相同表单与按钮。
- 对象与资料允许稍后补齐；保存草稿不要求通过运行检查。
- 输入、参考答案、实际输出分开；参考内容不得混入对象请求映射。
- 评分配置从模板带入，优先调整差异；可选映射、复核与来源折叠。
- 任务始终可见保存、预计成本和实际成本；未核实费用显示待核实。
- 冻结方案、执行状态、质量结论与业务验收分开显示。
- 已发布资产只读；补建资产不会静默替换任务引用。
- 旧套件、框架和既有运行使用原详情，保留历史演练行为。
- 支持窄屏、表格横向滚动、可见键盘焦点、原生对话框和未保存离开提示。
