# 逐接口产品模块映射与筛选修订

日期：2026-11-28。

base.json 保留原 180 条接口和技术模块方向；inventory.json 增加按操作明确的提供/调用产品模块和映射说明。主PRD P01—P15 全名沿用既有定义；同一技术模块不能一概映射到一个产品。来源：主PRD产品职责、协作与数据归属；概要 V2.4 §4.1；详设 V1.2逐接口合同。

产品映射为技术设计中的业务归属解释，不是生产运行调用统计；外部系统、出口基础设施不分配虚构P编号。服务提供方不能使用调用场景的并集代替能力归属；无独立归属的公共能力用范围说明，不强行绑定P编号。消息行按生产/消费方向映射，多生产者可成立。原 IF-Q01—06 继续保留。
