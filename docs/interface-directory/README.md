# 逐接口产品模块映射与筛选修订

日期：2026-11-28。

base.json 保留原 180 条接口和技术模块方向；inventory.json 增加按操作明确的提供/调用产品模块和映射说明。主PRD P01—P15 全名沿用既有定义；同一技术模块不能一概映射到一个产品。来源：主PRD产品职责、协作与数据归属；概要 V2.4 §4.1；详设 V1.2逐接口合同。

产品映射为技术设计中的业务归属解释，不是生产运行调用统计；外部系统、出口基础设施不分配虚构P编号。多产品项按对象类型/工作kind/用途区分。原 IF-Q01—06 继续保留。

## 已复现问题

线上原关键词搜索输入 P01，实际显示 op010—op019、op101，共11条，属于普通子串误命中；并非P01产品过滤。原技术模块过滤正常：资产管理22条、再加方案管理调用4条；消息事件17条。没有将正常功能宣称为全部失效。

## 修订

- 保留原技术模块两方向，增加提供方产品模块、调用方产品模块两列和独立搜索字段。
- 产品编号精确匹配，中文名/全名支持；全角字符统一，多个关键词取交集。
- 六个条件组合取交集，筛选后明确显示数量与状态，并回到表格顶部。
- 重置和64个技术模块快捷按钮清空产品条件，保留详情定位能力。
- 不新增下载入口，不修改接口权限/HTTP路径/既有未决项。
