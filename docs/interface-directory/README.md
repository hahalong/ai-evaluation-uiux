## 关键纠正

原表把技术实现的受益产品当作提供方；随后又将类型实现全部抹成公共能力，两次处理均不完整。现在区分公共契约、具体类型实现和服务调用：

- 公共EngineExecution契约保留CT38，不硬归属P04。
- P04明确提供AgentPlanner、AgentExecutor、多轮运行、模拟用户、成员交接、终态观测、恢复以及AgentCompass封装实现；接口所在技术模块和直接调用组件分别列出。
- P03模型策略/执行/OpenCompass、P05应用策略/执行同步补齐。
- Ragas/OpenCompass/AgentCompass评分封装归自动评分P06；场景使用产品不是评分服务所有者。
- 每个事件增加对应的消费处理器；消息生产→消费与处理器调用方向分开。work.kind和撤权订阅仍保留未决项。
- 模块附录A同步链接本清单，避免原CT摘要被误认为完整接口清单。
